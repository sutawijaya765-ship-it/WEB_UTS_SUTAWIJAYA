Tentang Saya

Mengenal lebih dekat profil, minat, dan tujuan saya

Siapa Saya?

Halo, perkenalkan nama saya Suta Wijaya. Saya merupakan mahasiswa Program Studi Sistem Informasi yang memiliki ketertarikan terhadap perkembangan teknologi informasi, khususnya dalam bidang pengembangan website. Saya senang mempelajari bagaimana sebuah website dirancang, dibangun, dan dikembangkan agar dapat memberikan informasi serta pengalaman yang baik bagi penggunanya.

Dalam proses belajar, saya mulai mengenal berbagai teknologi dasar pengembangan web, seperti HTML untuk menyusun struktur halaman, CSS untuk mengatur tampilan, serta Bootstrap untuk membantu menciptakan desain yang responsif. Saya juga mempelajari JavaScript agar website dapat memiliki fungsi interaktif dan tidak hanya menampilkan informasi secara statis.

Tujuan dan Pengembangan Diri

Saya menyadari bahwa kemampuan dalam bidang teknologi perlu terus dikembangkan melalui latihan, pengalaman, dan kemauan untuk mempelajari hal-hal baru. Oleh karena itu, saya berusaha memahami setiap materi yang dipelajari serta menerapkannya dalam bentuk latihan dan proyek sederhana. Bagi saya, proses mencoba, menemukan kesalahan, dan memperbaiki kode merupakan bagian penting dalam meningkatkan kemampuan pemrograman.

Ke depannya, saya ingin memperdalam pengetahuan dalam pengembangan website, meningkatkan kemampuan berpikir logis, serta membangun proyek digital yang bermanfaat. Saya juga ingin mengembangkan kemampuan bekerja secara terstruktur, menyelesaikan masalah, dan menggunakan teknologi secara kreatif. Melalui portfolio ini, saya berharap dapat mendokumentasikan proses belajar, menampilkan hasil karya, dan menunjukkan perkembangan kemampuan saya di bidang Sistem Informasi.
